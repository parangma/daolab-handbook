## 각 조 페이지를 읽는 법

모든 조 페이지는 같은 순서입니다. 질문이 좁혀진 과정 → 방법 → 지금까지 나온 것 → 가져다 쓸 도구 → 남은 일정과 비어 있는 것. 숫자에는 출처를 붙였고, 인용은 조 단위로만 밝혔습니다. 결과 칸 일부는 11월 11일 최종 공유회 뒤에 채워집니다.

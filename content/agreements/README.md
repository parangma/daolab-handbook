합의는 다오랩이 **지금 실제로 운영하는 방식**입니다. 새로 만든 규칙이 아니라, 정기모임 발제와 운영 기록에서 확인되는 것을 옮겨 적었습니다.

| 합의 | 한 줄 요약 |
|---|---|
| [멤버십: 루키와 크루](membership.md) | 들어오기는 일부러 어렵게. 두 달 수습 기수를 마치면 정식 크루 |
| [기여와 수료](contribution.md) | 기수 과정에서 역할을 하나 이상 맡는 것이 수료 조건 |
| [보상 원칙](rewards.md) | 거래가 아니라 인정. 점수보다 노출, 목표는 정체성 |
| [운영과 결정](operations.md) | 명시적 운영진이 없음. 승인 없이 누구나 열고 실행 |
| [기록과 개인정보](records.md) | 조 단위로만 분석하고 인용. 연락처와 얼굴 사진은 싣지 않음 |

엔스파이럴에서는 합의를 바꾸려면 정해진 절차를 거칩니다. 다오랩은 그 절차를 아직 정하지 않았습니다. 정할 때까지는 디스코드에 먼저 알리고 의견을 듣는 것으로 대신합니다.

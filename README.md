# 다오랩 8기 핸드북

다오랩이 어떻게 굴러가는지 적은 **살아 있는 문서**입니다.
[엔스파이럴 핸드북](https://handbook.enspiral.com/)처럼 멤버가 함께 고쳐 씁니다.

> 초안 v0.1 (2026-10-30). DAO LAB 8기 연구성과결과물팀이 8기 정기모임 발제, 다오포럼 자료,
> 조별 연구 기록을 바탕으로 엮었습니다.

## 고치는 법

웹에서 읽다가 고칠 곳이 보이면 페이지 위쪽 **이 페이지 고치기**를 누르세요.
GitHub에서 그 파일이 열립니다.

1. 내용을 고치고, 무엇을 왜 바꿨는지 한 줄로 적습니다.
2. 저장소 쓰기 권한이 없으면 GitHub가 자동으로 포크를 만들고 **풀 리퀘스트(PR)** 를 열어 줍니다.
3. **가이드**와 **이론 도구함**은 바로 반영해도 됩니다. **합의**를 바꾸는 PR은 디스코드에 먼저 알려 주세요.

GitHub가 낯설면 디스코드에 "핸드북 ○○ 페이지에 이런 내용이 틀렸어요"라고 남겨 주세요.
자세한 원칙은 [content/contributing.md](content/contributing.md)에 있습니다.

## 쓰는 원칙

- 지금 **실제로 하는 것**을 씁니다. 하고 싶은 것은 "제안"이라고 적습니다.
- 숫자에는 출처를 붙입니다: 자기보고 · 운영기록 · 문헌 · 공개자료.
- **개인 이름, 연락처, 얼굴 사진은 싣지 않습니다.** 인용은 '3조 조원 기록'처럼 조 단위로만.
  이 저장소는 공개되어 있어서, 커밋 기록에 남은 글은 지워도 기록에서 찾을 수 있습니다.

## 구조

```
content/
  SUMMARY.md        목차. 이 목록의 순서가 곧 장 번호이고, 목록에 있는 파일만 페이지가 됩니다.
  README.md         1. 들어가며
  contributing.md   1.1 이 핸드북을 고치는 법
  agreements/       2. 합의 — 신중하게 바꾸는 규칙
  guides/           3. 가이드 — 누구나 고치는 요령
  cohorts/          4. 기수와 조 (공동탐색연구, deep/ 조별 심층연구)
  resources/        5. 이론 도구함
  archive/          6. 지난 실험
src/                웹으로 보여 주는 코드 (Next.js)
```

새 페이지를 더하려면 `content/` 에 마크다운 파일을 만들고 `SUMMARY.md` 에 한 줄을 더하면 됩니다.
들여쓰기 두 칸이 한 단계이고, 3단계까지 씁니다. 본문의 물결표 `~` 는 `\~` 로 씁니다(두 개가 겹치면 취소선이 됩니다).

```md
- [가이드](guides/README.md)
  - [새 페이지 제목](guides/new-page.md)   ← 공백 두 칸 들여쓰기
```

## 내 컴퓨터에서 보기

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 목차에 있는데 파일이 없으면 여기서 멈춥니다
```
